# Year 4 SATs Prep - Free Practice Papers

**Free, auto-updating collection of Year 4 test papers for Maths, Reading, and English (GPS).** All papers are scraped weekly from UK primary school websites and verified accessible. Perfect for parents helping their Year 4 child prepare for SATs.

**[Open the collection -](https://sahirvhora.github.io/year4-prep/)**

## What's Inside

| Subject | Papers | Topics Covered |
|---------|--------|---------------|
| Maths | 14 | Arithmetic, four operations, fractions, measurement |
| Reading | 7 | Comprehension, inference, retrieval, vocabulary |
| English (GPS) | 15 | Grammar, punctuation, spelling, SPaG |

Every paper links directly to the PDF hosted by the school that published it. No sign-up, no paywall, no account needed.

## How It Works

1. **Automated scraper** runs every Sunday morning, searching UK school websites for new Year 4 papers
2. **Each paper is verified** - we check the link actually works before listing it
3. **The page updates automatically** - new papers appear without any manual edits

## Why I Built This

My daughter Misha is in Year 4. I wanted a single place where she could access all the free practice papers that UK schools publish online - without hunting through dozens of school websites every week. The scraper does the hunting for us.

## Tech

- Single HTML file with embedded CSS/JS - loads instantly
- Three JSON data files updated weekly by the scraper
- GitHub Pages for hosting
- Dark-themed UI designed for tablet and desktop use
- Dynamic term detection shows the right papers for the current school term

## For Parents

**How to use these papers with your child:**
- Start with one paper per week (15-20 minutes)
- Mark together and celebrate every improvement
- The "Currently: [Term]" banner shows which term's papers to focus on
- Switch between Maths, Reading, and English using the tabs at the top
- Verified papers show file size - "Click to try" ones need a browser to open
