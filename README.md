## Why This Exists

When my daughter Misha started Year 4, I spent hours hunting across school websites for free practice papers. Every school had a few, but nobody had collected them in one place. This site does that automatically:

1. **Automated scraper** runs every Sunday morning, searching UK school websites for new Year 4 papers
2. **Each paper is verified** - we download a sample from every link before listing it
3. **The page updates automatically** - new papers appear without any manual work
4. **Dynamic term detection** - the page knows which school term it is and highlights the right papers

## How to Use These Papers

**One paper per week is plenty.** Here's a routine that works:

- **Maths (Monday):** 10-15 minutes for an arithmetic paper. Mark together.
- **Reading (Wednesday):** 20-30 minutes. Read the passage first, then questions.
- **English GPS (Friday):** 15-20 minutes. Quick grammar and punctuation check.
- **Keep a score tracker:** Write the date, paper name, and score. The upward trend is motivating.
- **Times tables practice:** Year 4 pupils sit the Multiplication Tables Check (MTC). Use Mathsframe's free MTC simulator alongside these papers.
